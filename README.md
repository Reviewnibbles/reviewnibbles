# 🐰 reviewnibbles

A cozy little warren for testing the Reviewable dev server. Nothing here needs to make sense — it just needs to compile (mostly) and give the Review Animals something to sink their teeth into.

## Who's in the burrow

- **🕵️ Inspector Shelly** — a tortoise who never misses a clue, mostly because she has nowhere else to be. Slow to comment, fast to catch the bug you were hoping nobody would notice.
- **✍️ Writer Robin** — an early bird with early opinions. Pecks out changelogs before the worm's even awake and always has a witty line-comment ready to go.
- **🐇 Review Bunny** — hops straight to the diff, thumps twice for LGTM. Owns the whole warren but still shows up to review every carrot-related PR personally.

## What this repo is for

Just a nibble-sized sandbox for poking at the Reviewable dev server — branches, PRs, comments, the works. Expect test commits, placeholder code, and the occasional bad pun in a commit message. If it breaks, that's the point.

## Contributing

1. Clone the warren.
2. Nibble on some code.
3. Open a PR and let the animals review it.
4. Hop away victorious (or get sent back for changes — happens to the best of us).

🥕 Happy reviewing!
